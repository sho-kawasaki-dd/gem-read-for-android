# User Manual Screenshot Assets

This directory is reserved for screenshots used by [docs/user_manual.md](../../user_manual.md).

## Recommended file names

- `home-screen.png`
- `settings-screen.png`
- `share-text-flow.png`
- `share-image-flow.png`
- `process-text-flow.png`
- `result-screen.png`
- `history-screen.png`
- `template-management-screen.png`

## Capture notes

- Use the current implemented UI only.
- Prefer Japanese UI labels, because the app strings are currently Japanese-first.
- Use one screenshot per section unless a flow needs two steps.
- If sensitive data is visible, mask the API key before saving the image.

## Suggested alt text pattern

- `Home screen of Gem Read`
- `Settings screen with API key and model selection`
- `Result screen showing Gemini response`
